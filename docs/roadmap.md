# 持续开发路线

每阶段按完整用户闭环推进，不以目录存在等同功能完成。

| 阶段 | 交付 | 验收关键点 |
|---|---|---|
| 0 初始化 | 需求、架构、目录、本机 Go 健康检查 | 测试和构建；明确未实现范围 |
| 1 基础助手 | 安卓聊天、单主机器人、历史、后台任务 | 关 APP 后任务继续，重开恢复状态 |
| 2 小程序底座 | WebView、应用中心、资源包、数据 SDK、缓存 | 手工待办可用；离线、版本切换、跨应用隔离真机验证 |
| 3 AI 创建小程序 | 草稿、校验、预览、发布、更新 | 一句话创建待办，聊天和页面操作同一数据，升级不丢数据 |
| 4 记忆与账号 | 可管理记忆、Gmail 只读、邮件看板 | 撤销授权有效；外部内容不能诱导越权 |
| 5 多机器人与自动化 | 专用机器人、受控委派、定时任务、通知 | 权限不扩大；预算、次数、超时与幂等生效 |

当前优先级：尽快完善聊天相关功能。小程序保留入口及现有实现，真实生成闭环推迟完善，不阻塞当前代码提交。
